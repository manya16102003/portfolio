**Portfolio Management Application**

This repository contains a Portfolio Management Application, a Spring Boot project designed to help users manage their stock portfolios. The application connects to a MySQL database for data persistence and leverages Spring Data JPA for seamless integration. Below is a detailed overview of the project and how to set it up.

Features

Portfolio Management: Track your stocks and investments easily.

Spring Boot Framework: Robust and scalable application development.

Database Integration: Utilizes MySQL for persistent storage.

HikariCP Connection Pooling: High-performance database connection management.
